# AI-Powered Behavioural Anomaly Detection for Cybersecurity

An AI-powered behavioural anomaly detection platform that models normal user and device behaviour, detects cyber anomalies in near real-time, classifies attack types, and provides explainable risk scores through an analyst-focused dashboard.

---

## Features

- Synthetic behavioural log generation
- Behaviour profiling
- Sequence-aware anomaly detection
- Attack classification
- Explainable AI
- Risk scoring
- Analyst dashboard
- Concept drift handling
- Cold-start support
